# 状态与文案规范 v1（长任务 / 权限 / 风控）

Status: `active`
Depends on: [`DESIGN.md`](../../../DESIGN.md)
Scope: `interaction / product behavior`
Does not define: `global tokens / route truth / engineering gates`

## 1. 通用状态

- Loading：骨架屏（表格/列表）+ 细粒度 spinner（按钮）
- Empty：解释“为什么为空” + 提供下一步 CTA
- Error：提供 `error_code`（可复制）+ `request_id`（可复制）+ 建议动作

## 2. 权限与可见性

- 403 文案必须区分：
  - 未加入 project
  - 已加入但无权限点
- UI 不显示无权限按钮，但允许通过深链进入后看到无权限提示

## 3. Agent tasks / Chat 长任务状态

turn / run 状态：
- queued
- started
- completed
- cancelled
- error

断线恢复：
- SSE 断开：`Disconnected. Reconnecting…`
- 恢复成功：`Recovered`

## 4. Agent Runners / Endpoints / Files 风控文案

统一模式：
- rate limited：`Rate limited. Please retry later.`
- limit exceeded：`Limit exceeded. Contact project admin to increase limits.`
- invalid argument/query：`Invalid request.` + 可修复提示

## 5. Files 处理状态文案

文件状态：
- queued
- processing
- ready
- failed

当前产品名称统一使用正式对象名，例如 `Files` 或 `shared project library`。
