# 页面清单（v1）：模块、权限可见性与关键字段

日期：2026-01-31

---

## 1) 约定

- UI 角色按权限点模板映射：owner/admin/developer/user（最终以权限点集合为准）
- “只读可见”与“可管理”必须在 UI 上明确区分（按钮/入口是否出现）
- 任何危险操作（revoke key、rotate credential、clear userdata）必须二次确认并记录 request_id

---

## 2) 页面清单（v1）

### 2.1 登录与全局
- Login（JWT）
- Workspace Switcher（列表/搜索）
- Workspace Settings（工作区设置）
- Profile（基本信息、退出）
- User API Keys（usk 管理：创建/查看/撤销）

### 2.2 Project
- Project List/Discover
  - public/private 标识
  - join 状态（member / pending / not_member）
- Project Overview
  - KPI：turns、errors、queued、online agents、endpoint requests、userdata usage

### 2.3 Workbench
- Workbench Workspace（NotebookLM-like 布局）
  - 左侧 Sources：文件上传/列表/状态（queued/processing/ready/failed）
  - 中间 Thread：消息区（SSE 流式输出）
  - 右侧 Context：current agent、handoff、thread 状态与操作（close/cancel）
- Threads List（可选：如不做单独列表页，则在 Workbench 顶部提供 thread 切换器）

### 2.4 Agents
- Agents List
  - mode（external/internal）
  - presence（online/offline/managed）
  - status（enabled/disabled）
  - active_sessions（internal）
- Agent Detail
  - 基本信息
  - internal config（owner/admin 可编辑；developer 只读或不可见）
  - managed_diagnostics（owner/admin 可见 message）
- Agent Keys（ask）
  - create/suspend/resume/revoke

### 2.5 Endpoints
- Endpoints List/Detail
  - openai_model、status、limits 摘要
  - disable/enable/rotate（owner/admin）
- Endpoint ACL（deny list）
  - 搜索用户、添加 deny、移除 deny

### 2.6 Members
- Members List（权限点集合展示）
- Join Requests（审批）

### 2.7 Audit & Usage
- Audit（按 action/resource/actor 过滤）
- Usage（按 resource_type、agent、end_user 过滤；图表+表格）

### 2.8 Settings
- Project Config（给 agent 读的结构化 config）
- Project Policy（配额/限流/护栏/能力开关）
### 2.9 Chat（必须，v1）
- Chat Workspace（NotebookLM-like 布局）
  - 左侧 Sources：文件上传/列表/状态（同 Workbench，可复用）
  - 中间 Chat：OpenAI 兼容 chat.completions 的 UI（流式输出）
  - 右侧 Context：model（openai_model）选择、基础参数（v1 可不做高级参数）
