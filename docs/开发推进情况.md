- **Route gate 契约**：`docs/contracts/route-gate-test-checklist.md` 要求受保护路由具备 param 校验、门禁与对应单元测试（success / invalid-param / forbidden）。当前实现与契约一致。

- **契约检查脚本**：
  - `npm run contracts:check`：门禁与路由契约检查。
  - `npm run contracts:check-openapi`：OpenAPI 核心覆盖、route-kind、破坏性变更。
  - `npm run openapi:generate` / `npm run openapi:check-generated`：前端类型与 OpenAPI 同步。
- **发布前**：main 分支上 `npm run contracts:check` 与 `npm run contracts:check-openapi` 须通过；OpenAPI 类型须与后端一致（`npm run openapi:check-generated`）。
