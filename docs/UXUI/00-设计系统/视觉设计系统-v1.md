
这份设计手册旨在为 UX/UI 设计师提供一套完整、自包含的视觉与交互准则，以便在不参考原始代码的情况下，还原 Google AI Studio 这种“专业开发者工具感”且“充满 AI 智能感”的设计风格。
AI Studio 视觉设计规范手册 (Design System Manual)
1. 设计核心理念 (Core Concept)
专业主义 (Professionalism): 界面沉稳，减少装饰性元素，强调数据和功能的优先级。
深色效率 (Dark Efficiency): 以深灰色系为底，降低长时间工作的视觉疲劳。
AI 灵感 (AI Infused): 通过微妙的色彩渐变、特定的图标符号（如火花图标）来传达产品的技术深度与智能化。
2. 色彩系统 (Color System)
手册以深色模式为核心。所有色彩应保持低饱和度，确保文字在高对比度下的易读性。
2.1 背景色阶 (Background Hierarchy)
底色 (Background): #141313 — 用于页面的最底层背景。
侧边栏 (Sidebar): #191919 — 略亮于底色，用于侧边固定导航。
卡片/容器 (Surface): #1E1F20 — 内容区域的主要承载面。
高亮容器 (Surface High): #282A2C — 用于嵌套容器或需要突出显示的区域。
悬浮状态 (Hover): #323232 — 元素在鼠标悬停时的背景色。
2.2 品牌与语义色 (Brand & Semantic)
主行动色 (Primary Blue): #87A9FF — 用于链接、主要按钮、高亮图标。
AI 渐变 (AI Gradient): 从 #B1C5FF 到 #076EFF (线性 90度) — 仅用于重点标题或 AI 专属特征。
成功色 (Success): #3DDB85 — 用于状态指示。
错误色 (Error): #F44336 — 用于告警提示。

2.3 对话框专用色 (Dialog-specific)
对话框背景 (Dialog): #2F3134 — 比 Surface 略亮，浮于主背景之上。
输入框背景 (Input): #424548 — 比对话框更亮，突出可交互区域。
输入框边框 (Input Border): #4A4D52 — 细边框，定义输入区域。
2.4 边框与分割线 (Borders)
基础边框: #333333 — 极细，用于区分卡片边界。
深色边框: #262626 — 用于更隐蔽的区域划分。
3. 字词排版 (Typography)
首选字体: Inter (若无 Inter，则使用系统默认的 Sans-serif)。
字号规范:
大标题 (Level 1): 24px, Semi-bold (用于页面主标题)。
中标题 (Level 2): 16px, Semi-bold (用于模块、卡片标题)。
正文 (Body): 14px, Regular (默认字号)。
次要文本 (Small): 12px, Regular (用于说明信息、表头)。
文本颜色:
高亮文本: #FFFFFF (用于重要标题)。
主要文本: #D4D4D4 (用于正文内容)。
次要文本: #8C8C8C (用于变量、占位符、不重要的元数据)。
4. 空间与几何 (Grid & Geometry)
间距单位: 基数为 4px。常用间距：8px, 12px, 16px, 24px, 32px。
圆角规范 (Border Radius):
标准按钮/标签: 8px
内容卡片/对话框: 12px
功能模块 (大容器): 16px
胶囊形按钮 (Pill): 20px 或以上
侧边栏宽度:
- 标准展开宽度: 192px（当前实现，空间密度优化）
- 折叠宽度: 72px
5. 组件规范 (UI Components)
5.1 侧边导航栏 (Sidebar)
项目高度: 40px。
状态表现:
默认: 背景透明，文本色为 #D4D4D4，配有 20px 大小的线性图标。
选中态: 背景填充 #323232，文本色变为白色，左侧可配有细长的蓝色指示条。
底部固定区: 用户头像、设置、API Key 等入口固定在底部。
5.2 功能卡片 (Feature Cards)
静态样式: 背景 #1E1F20，边框 1px 实线 #333333。
布局: 左侧或顶部放置 24px 大小的彩色/渐变图标。
悬停感官: 边框色微亮（或变为白色），光标变为 Pointer。
5.3 按钮 (Buttons)
主要按钮 (Outline/Ghost):
无填充或半透明填充，边框 1px。
文字与图标居中，字重 500。
行动按钮 (Action Button):
用于页面级工具栏操作（如 Create/New/Upload/Refresh），采用较深的灰色背景 #323232，文字白色或高对比浅色，边框 1px 细线。
主要确认按钮 (Primary Button):
用于对话框/抽屉内提交动作（如 Create/Save/Confirm/Send），可使用品牌蓝 #87A9FF 实心填充，保证主次分明。

按钮使用映射（全站统一）:
- `action`: 页面 Header/Toolbar 内“新建/创建/上传/刷新”等入口动作。
- `primary`: Dialog/Drawer/Form 内“提交/保存/发送/确认”等主动作。
- `outline`: 表格与列表的次级动作（管理、下载、批量操作）。
- `ghost`: 行内轻量动作（取消、关闭、图标操作）。
5.4 统计与数据表格 (Data Display)
表头: 背景透明，文本 12px，全大写或深灰色，下方配有 #262626 的单像素线。
数据行: 文本 14px，间距紧凑，无垂直边框。
紧凑模式: 行高可缩减至 36px，padding 8px 12px，适用于文件列表等大量数据场景。支持分页。

5.5 复选框与多选 (Checkbox & Selection)
深色背景下必须保证可见性与对比度：
- 未选中: 边框 #4A4D52 (与输入框边框一致)，背景透明或 #424548，圆角 4px，尺寸 16×16px 或 18×18px。
- 选中: 背景 #87A9FF，边框同色，勾选图标白色 (#FFFFFF)，确保与背景对比度 ≥4.5:1。
- 悬停: 边框微亮至 #5A5D62 或 #87A9FF 半透明。
- 禁用: 透明度 50%。
- 表格多选: 表头全选与行选使用同一套样式；选中行背景使用 rgba(135,169,255,0.08) 区分。
- 批量操作栏: 多选时在表格上方或下方显示固定操作区，背景 #282A2C，边框 #262626，内边距 12px 16px，操作按钮右对齐。

5.6 对话框 (Dialog / Modal) 与侧边栏 (Side Panel)

**使用边界**：详见 [对话框与侧边栏使用规范](对话框与侧边栏使用规范-v1.md)。
- **Dialog**：仅用于简单交互（1～2 个输入、确认/选择、展示结果）。
- **Side Panel**：用于复杂交互（多字段表单、权限/配额配置、多 Tab 等），从右侧滑出，风格与成员权限配置界面一致。

**Dialog 容器 (Dialog Container):**
- 背景色: #2F3134 — 比应用主背景 (#1E1F20) 略亮，使对话框从页面中浮出
- 圆角: 12px，保持柔和现代感
- 阴影: 柔和深色投影 (blur 16px, spread -4px, 黑色 10% 透明度)，营造悬浮感
- 内边距: 上下左右 24px，保证内容呼吸感

**头部 (Header):**
- 标题: 粗体，16–18px，左对齐，白色 (#FFFFFF)
- 关闭按钮: 右上角 X 图标，不显眼但易发现，悬停时提高不透明度
- 无分割线，通过留白与正文区分

**表单元素 (Input / Select / Textarea):**
- 背景色: #424548 — 比对话框背景更亮，明确标识为可交互区域
- 边框: 1px 细边框，浅灰色 (#4A4D52)，定义边界但不抢眼
- 圆角: 8px，与整体风格一致
- 占位符: 中灰 (#8C8C8C)
- 标签: 输入框上方，14px，常规字重，白色或浅灰

**操作按钮 (Footer Actions):**
- 布局: 右对齐，主按钮与次按钮水平排列
- 次要按钮 (Cancel): 纯文字按钮，无背景无边框，文字浅灰 (#D4D4D4)，表示次要/取消操作
- 主要按钮 (Create / Submit): 实心填充，背景 #87A9FF 或深灰 #424548，文字白色，字重 500，圆角 8px，视觉权重最高

**设计原则:**
- 层次背景: 应用背景 < 对话框背景 < 输入框背景，形成清晰层级
- 主次分明: 主要操作使用实心高对比按钮，次要操作使用文字按钮
- 统一圆角: 对话框 12px，输入框与按钮 8px
- 留白充足: 标题、标签、输入、按钮之间保持 16–24px 垂直间距

6. 图标与 AI 元素 (Iconography & AI)
图标风格: 统一使用 线性 (Outlined) 风格，线条粗细一致（约 1.5px - 2px）。
AI 特征:
使用“火花 (Sparkle)”图标来代表 AI 功能。
对于 Gemini 等特定模型，使用专属的蓝紫色渐变图标。
图标颜色: 默认为 #C4C6CF，激活或高亮时使用 #87A9FF。
7. 交互体验 (Interaction Details)
转场动画: 元素状态切换（如 Hover 背景色变化）使用 200ms 的平滑渐变。
阴影使用: 极少使用阴影。仅在浮动的弹窗 (Dialog) 或下拉菜单中使用柔和的深色投影（Blur 16px, Spread -4px, 颜色为纯黑且透明度 0.1）。
滚动条: 窄化处理，滑块颜色设为 #333333，轨道透明。
8. 页面结构 (Page Chrome)
统一的页面结构应包含：Header（标题/描述/主行动）、Toolbar（筛选/次要操作）、Body（内容区）、可选 Footer。
- Header: 使用 Level 1 标题（24px），必要时提供 1 行副标题（12–14px，次要文本）。
- Toolbar: 仅在存在操作/筛选时显示，避免空 Toolbar 造成多余空白。
- Body: 内容区由 PageLayout 统一提供密度化外边距，避免局部再加 `p-6` 造成双重内边距。
- PageLayout 密度规范（2026-02-07）：
  - `default`：`padding=16px`，`gap=16px`
  - `immersive`：`padding=8px`，`gap=8px`
- 状态展示: Loading/Empty/Error 统一居中呈现（推荐 `px-4 py-6`）；Success 保持顶部对齐并允许内容区内部滚动。
- 沉浸式页面建议：
  - Chat、AI Studio（含 Task 详情）应优先使用 `immersive`，减少外圈留白，提升信息密度。
  - 数据密集页面（列表/表格）默认使用 `default`，必要时仅对局部区域做紧凑化。
 - 表单配置页面（如 Project Settings）应使用 `max-w-6xl` 级容器，并优先采用双列信息布局（名称/可见性并排）以减少无效留白。
 - 成员治理页面（Members）避免双层主导航标签：`People / Requests / Templates / Groups` 应位于顶层单层 Tabs，降低认知成本。
 - 资源策略页面（Resource Policy）编辑区应拆分为“资源头信息 / 访问模式 / 主体覆盖 / 资源限额 / 生效摘要”分区卡片，避免单块长表单造成理解负担。
 - Endpoints 数据表动作列在桌面端应优先使用“图标 + 文本”组合（如 Edit / Disable / Delete），仅在窄宽度退化为纯图标，确保可理解性。

9. 设计检查清单 (Final Checklist)
对比度: 文字是否在深色背景下足够清晰？（检查正文是否为 #D4D4D4）。
一致性: 所有圆角是否符合 8px/12px/16px 的分级？
克制感: 是否使用了多余的颜色？整个界面应以灰黑白为主，蓝色仅作为引导。
对齐: 侧边栏图标与文字是否垂直居中对齐？内容区是否使用了统一密度外边距（default 16 / immersive 8）？
对话框: 容器、输入框、按钮是否有清晰的背景层次？主次按钮是否区分明显？
手册使用建议： 任何设计人员在启动新页面设计时，应先搭建好底色（#141313）和侧边栏（#191919），然后使用卡片（#1E1F20）进行内容切割，最后点缀品牌蓝色。
