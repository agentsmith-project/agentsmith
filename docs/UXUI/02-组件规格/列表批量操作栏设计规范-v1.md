# 列表批量操作栏设计规范 v1

Status: `active`
Depends on: [`DESIGN.md`](../../../DESIGN.md)
Scope: `interaction / product behavior`
Does not define: `global tokens / route truth / engineering gates`

日期：2026-02-03  
目标：定义带行选择的列表页面中，批量操作栏的布局与交互规范，避免选择时出现布局跳变。  
参考实现：Sources 页面、Members 页面。

---

## 1) 问题与目标

### 1.1 问题
当用户勾选列表中的多行时，若批量操作栏以**流式布局**插入在列表上方，会导致：
- 列表整体下移
- 用户视线中的行位置发生跳变
- 体验不佳

### 1.2 目标
- 选择时**不产生布局跳变**
- 操作栏始终可见、易触达
- 长列表时最后几行仍可滚动到操作栏上方查看

---

## 2) 设计原则：底部悬浮覆盖

### 2.1 核心思路
批量操作栏**不参与流式布局**，而是以**绝对定位**悬浮在列表区域底部，覆盖在内容之上。

### 2.2 布局结构

```
┌─────────────────────────────────────┐
│  Header / Filters (flex-shrink-0)   │
├─────────────────────────────────────┤
│  ┌───────────────────────────────┐   │
│  │  List/Table (overflow-auto)  │   │  ← flex-1 min-h-0
│  │  ...                         │   │  ← 有选择时加 pb-14
│  │  ...                         │   │
│  └───────────────────────────────┘   │
│  ┌───────────────────────────────┐   │
│  │  Batch Action Bar (absolute)  │   │  ← 悬浮覆盖底部
│  └───────────────────────────────┘   │
└─────────────────────────────────────┘
```

### 2.3 关键实现要点

| 层级 | 样式 | 说明 |
|------|------|------|
| 外层容器 | `flex-1 min-h-0 flex flex-col relative` | 提供定位上下文，占满剩余高度 |
| 滚动区域 | `flex-1 min-h-0 overflow-auto` | 列表在此区域内滚动 |
| 滚动区域（有选择时） | `pb-14`（约 56px） | 底部留白，使末行可滚动到操作栏上方 |
| 操作栏容器 | `absolute bottom-0 left-0 right-0 z-10` | 悬浮在底部 |
| 操作栏 | `border-t bg-surface shadow` | 与内容区分，带顶边与阴影 |

---

## 3) 页面布局前置条件

本模式要求**列表区域有独立滚动**，而非整页滚动。因此页面需满足：

1. **页面根容器**：`h-full flex flex-col`，占满视口高度
2. **列表区域**：`flex-1 min-h-0`，占据剩余空间并可收缩
3. **列表内部**：`overflow-auto`，在区域内滚动

若页面为整页滚动（无固定高度），则需先调整布局（如增加 `layout` 提供 `h-full`），否则操作栏会随内容滚动到底部，无法固定在可视区域底部。

---

## 4) 边界情况与处理

### 4.1 长列表
- 列表在滚动区域内滚动
- 操作栏固定在区域底部
- `pb-14` 保证末行可滚动至操作栏上方，不被遮挡

### 4.2 短列表（内容不足一屏）
- 操作栏仍悬浮在区域底部
- 底部留白由 `pb-14` 提供，不影响布局稳定性

### 4.3 空列表
- 通常无选择，不显示操作栏
- 若存在“全选空态”等特殊逻辑，操作栏仍按悬浮方式展示

### 4.4 分页切换
- 建议在切换页码时**清空选择**，避免跨页选择语义混乱
- 参考：Sources 在 `page` 变化时 `setSelectedIds([])`

### 4.5 Tab 切换
- 若列表在 Tab 内，切换 Tab 时操作栏随 Tab 内容隐藏
- 选择状态可保留或清空，视产品需求而定

## 5) 参考实现

- **Files 页面**：`FilesPage.tsx` + `FilesSelectionBar.tsx`
- **Members 页面**：`MembersPage.tsx` + `BatchApplyBar.tsx`

两处均采用：
- 底部悬浮覆盖
- `pb-14` 预留滚动空间
- `overlay` 模式（操作栏组件无独立圆角/边框，由容器提供顶边与阴影）

---

## 6) 组件接口建议

操作栏组件建议支持 `overlay` 属性，用于悬浮模式下的样式切换：

```tsx
interface BatchActionBarProps {
  // ...
  overlay?: boolean;  // 悬浮模式：无圆角/边框，由外层容器提供顶边
}
```

- `overlay: true`：仅背景与内边距，用于悬浮
- `overlay: false`：完整边框与圆角，用于流式布局

---

## 7) 不做（防膨胀）

- 不强制所有列表页使用此模式；无批量操作的列表无需操作栏
- 不在此规范中定义具体操作按钮（Apply、Delete 等），由各业务页面自行实现
