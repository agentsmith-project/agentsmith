# 列表批量操作栏设计规范 v1

Status: `active`
Depends on: [`DESIGN.md`](../../../DESIGN.md)
Scope: `interaction / product behavior`
Does not define: `global tokens / route truth / engineering gates`

目标：定义带行选择的列表页面中，批量操作栏的布局与交互规范，避免选择时出现布局跳变。

参考实现：Files 页面、Members 页面。

## 1. 核心原则

- 选择时不产生布局跳变
- 操作栏始终可见、易触达
- 长列表时最后几行仍可滚动到操作栏上方查看

## 2. 布局模式

批量操作栏不参与流式布局，而是以底部悬浮覆盖模式展示。

关键实现点：
- 外层容器：`flex-1 min-h-0 flex flex-col relative`
- 滚动区域：`flex-1 min-h-0 overflow-auto`
- 有选择时滚动区域追加 `pb-14`
- 操作栏容器：`absolute bottom-0 left-0 right-0 z-10`

## 3. 当前产品命名

- 批量操作栏里的对象名直接使用当前正式产品名
- Files 场景使用 `Files` 或 `shared project library`
- 成员治理使用 `Members`
- 治理链路使用 `Policy`

## 4. 组件接口建议

操作栏组件可支持 `overlay?: boolean`：
- `overlay: true`：悬浮模式
- `overlay: false`：流式模式
