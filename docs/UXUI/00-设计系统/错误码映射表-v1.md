# 错误码 → UI 文案映射表 v1（zh-CN / en-US）

Status: `active`
Depends on: [`DESIGN.md`](../../../DESIGN.md)
Scope: `interaction / product behavior`
Does not define: `global tokens / route truth / engineering gates`

规则：
- UI 永远显示 `error_code` 和 `request_id`
- UI 文案只负责用户可理解解释与下一步动作
- 未知 `error_code` 统一展示未知错误，但保留原始 `error_code`

## 通用错误

| error_code | zh-CN 标题 | en-US Title | 推荐 CTA |
| --- | --- | --- | --- |
| `INVALID_ARGUMENT` | 请求无效 | Invalid request | Retry |
| `NOT_FOUND` | 未找到资源 | Not found | Back |
| `PERMISSION_DENIED` | 无权限 | Permission denied | Back to projects |
| `RATE_LIMITED` | 请求过于频繁 | Rate limited | Retry |
| `SPENDING_LIMIT_EXCEEDED` | 配额不足 | Limit exceeded | View limits |

## Chat / Endpoints / Agent Runners

保留当前通用映射：
- `model_not_found`
- `model_invalid`
- `ENDPOINT_DISABLED`
- `ENDPOINT_PERMISSION_DENIED`
- `ENDPOINT_UPSTREAM_TIMEOUT`
- `ENDPOINT_UPSTREAM_ERROR`
- `KEY_REVOKED`
- `KEY_SUSPENDED`
- `KEY_EXPIRED`

## Files

当前产品名称使用正式对象名：
- `UPLOAD_FAILED`
- `PROCESS_FAILED`

如果插件或上游返回更细粒度 error_code，应在 current contract 与这份映射表里一起补齐。
