# 对话框与侧边栏使用规范 v1

日期：2026-02-03  
目标：明确 Dialog（对话框）与 Side Panel（右侧浮动侧边栏）的使用边界，确保复杂交互场景的体验一致。

---

## 1. 设计原则

**简单用 Dialog，复杂用 Side Panel。**

- **Dialog**：适用于轻量、快速、一次性完成的交互。
- **Side Panel**：适用于多步骤、多字段、需要沉浸式配置的复杂交互。

### 1.1 强制规则（2026-02-06 生效）

- 只要交互内容“偏重”（见第 3 节判定），**必须使用右侧浮动 Side Panel（Sheet）**。
- Dialog 仅保留最简单交互：确认/取消、单项选择、1-2 个输入项的快速提交。
- 新增功能默认先按 Side Panel 设计；只有明确满足“轻量交互”才允许降级为 Dialog。

---

## 2. Dialog（对话框）适用场景

**仅限简单交互**，满足以下任一条件时使用 Dialog：

- **输入极少**：1～2 个输入框，或单个选择器（如 Select）
- **展示为主**：以展示信息为主，附带简单确认/取消
- **快速决策**：用户只需做「确认 / 取消」或「选择一项」等简单操作

**典型用例**：
- 确认删除（AlertDialog）
- 单行输入 + 确认（如重命名）
- 选择一项（如选择成员应用模板）
- 展示结果 + 复制链接（如邀请链接已生成）

**实现**：使用 `Dialog` 组件，居中浮层，尺寸适中（如 `sm:max-w-[420px]`）。

---

## 3. Side Panel（右侧浮动侧边栏）适用场景

**复杂交互一律使用右侧侧边栏**，满足以下任一条件时使用 Side Panel：

- **多字段表单**：3 个及以上输入/选择区域
- **分组配置**：存在 Tab、分组、或需要切换视图的配置
- **权限/配额等精细配置**：大量复选框、多维度配置（如成员权限、配额覆盖、资源 ACL）
- **需要参考主列表**：用户可能需要在侧边栏与主列表之间来回对照
- **内容高度超出一屏**：需要滚动阅读/编辑
- **包含高级配置区**：折叠区域、可变行（如动态键值对）、结构化配置块

**典型用例**：
- 成员权限与配额配置（MemberDetailDrawer）
- 创建/编辑权限模板（CreateTemplateDrawer、EditTemplateDrawer）
- 创建/编辑复杂资源（如 Agent、Endpoint 的完整配置）
- 多 Tab 的配置面板

**实现**：使用 `Sheet` 组件，`side="right-wide"`，宽度 `sm:w-[640px]`，与成员详情抽屉风格一致。
- 固定头部（标题 + 副标题/描述）
- 可滚动内容区（`flex-1 min-h-0 overflow-y-auto`）
- 底部固定操作栏（Cancel / Save）

### 3.1 当前代码库落地要求

- 以下创建/编辑表单统一按 Side Panel 实现：
  - Project 创建/编辑
  - Agent 创建/编辑
  - Endpoint 创建/编辑
  - 成员权限/配额/ACL 配置
- 允许保留 Dialog 的仅限：
  - 删除确认、危险操作确认（AlertDialog）
  - 邀请成功结果确认、复制链接等轻量反馈
  - 单输入或双输入快速表单

## 4. 侧边栏布局规范

参考 `MemberDetailDrawer` 的实现：

```
┌─────────────────────────────────────────┐
│  Header (flex-shrink-0)                  │
│  - 标题 (text-base font-semibold)       │
│  - 副标题/描述 (text-sm text-tertiary)   │
│  - 可选：Badge、操作按钮                 │
├─────────────────────────────────────────┤
│  Content (flex-1 min-h-0 overflow-y-auto)│
│  - 表单、Tab、列表等                     │
│  - 内边距：px-6 py-4                    │
├─────────────────────────────────────────┤
│  Footer (flex-shrink-0)                  │
│  - 右对齐：Cancel | Primary Action       │
│  - 内边距：px-6 py-4 border-t            │
└─────────────────────────────────────────┘
```

**关键样式**：
- `SheetContent`: `flex flex-col p-0 gap-0 h-full overflow-hidden sm:w-[640px]`
- 头部、底部 `border-subtle` / `border-border` 分隔

---

## 5. 决策流程图

```
需要弹层交互？
    ├─ 是 → 输入/配置项是否 ≥ 3 个？或存在 Tab/分组？
    │       ├─ 是 → 使用 Side Panel
    │       └─ 否 → 是否为简单确认/选择？
    │               ├─ 是 → 使用 Dialog
    │               └─ 否 → 使用 Side Panel（保守选择）
    └─ 否 → 使用内联或页面内表单
```

---

## 6. 实施检查清单

- [ ] 新建「创建/编辑」类功能时，先判断字段数量与复杂度
- [ ] 3+ 字段或含权限/配额等精细配置 → 使用 Sheet 侧边栏
- [ ] 1～2 字段或纯确认/选择 → 使用 Dialog
- [ ] 侧边栏实现与 MemberDetailDrawer 布局一致（Header / Content / Footer 三段式）
- [ ] 重内容表单统一使用 Sheet 侧边栏，禁止使用重内容 Dialog
