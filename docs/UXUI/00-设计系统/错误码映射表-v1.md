# 错误码 → UI 文案映射表 v1（zh-CN / en-US）

日期：2026-01-31  
目标：统一前端对后端 `error_code` 的呈现方式，避免不同页面出现不一致文案；同时保证可运营排障（必须展示 `error_code` + `request_id`）。  

规则（必须）：
- UI 永远显示：
  - `error_code`（不翻译，可复制）
  - `request_id`（不翻译，可复制）
- UI 文案只负责“用户可理解的解释 + 下一步动作”，不覆盖后端错误语义。
- 若收到未知 `error_code`：
  - zh-CN：展示“发生未知错误”
  - en-US：展示“Unknown error”
  - 仍展示 `error_code` 原值 + `request_id`
