# MBOS Agent Platform - Marketing Copy (English)

---

## Headline

**MBOS: Enterprise-Grade Agent Governance Platform**

One-stop management and consumption of AI agents. Secure, controllable, ready to use.

---

## Core Value Proposition

### One-line

> A project-centric agent governance platform that enables enterprises to securely and efficiently onboard and manage AI agents.

### Three Pillars

1. **Governance Hub** — Resources, permissions, limits, usage, and audit unified in one Project
2. **Fine-Grained Permissions** — Two-tier access control (platform + resource), deny wins, least privilege
3. **Resource Control** — Multi-dimensional rate limits, limit overrides, configuration checks, tiered coverage

---

## Feature Highlights

### Multi-Tenancy & Project Management

- **Workspace = Tenant** — Native SaaS isolation
- **Project = Governance Unit** — Clear ownership of resources, members, policies, and usage
- **Visibility Control** — Public / Private with join approval flow

### Permissions & Members

- **Four Role Templates** — Owner / Admin / Developer / User

- **Full Permission Coverage**:
  - Platform: Workspace, Project, Membership, Policy, Files, Tasks, Agent, AgentThread, UserData
  - Resource: KB and Endpoint ACLs

- **Member Limit Overrides** — Per-user limit customization with history tracking

### Agent Management

- **External Agent** — WebSocket connection from external networks, long-running
- **Internal Agent** — Platform-hosted, pod-launched per session
- **Agent Service Key** — Issued per agent, plaintext returned only once

### Resources & Proxy

- **UserData Capabilities** — DocDB, VectorDB, Storage, strongly isolated per end-user
- **Shared Endpoints** — LLM/HTTP outbound proxy, secret values hidden
- **Files** — Upload, file browsing, pagination

### Audit & Usage

- **Audit Logs** — Full traceability for compliance
- **Usage Statistics** — Requests, tokens, path distribution

### Configuration & Policy

- **Governance Rules** — Limits, rate limits, checks — JSON config
- **Resource Limits** — Project-level caps, dynamically adjustable

## Use Cases

- **Enterprise AI Apps** — Unified agent onboarding and governance
- **Multi-Team Collaboration** — Project isolation with clear permissions and limits
- **Compliance & Audit** — Full operation logging and usage billing
- **Hybrid Deployment** — Same architecture for SaaS and on-premise

---

## Technical Advantages

- **Two-Tier Permissions** — Edge coarse-grained + Backend fine-grained
- **AgentThread Trust Context** — end_user derived server-side, non-forgeable
- **Multi-Dimensional Rate Limiting** — Workspace / Project / Actor layers
- **PostgreSQL + MongoDB** — Strong consistency for critical data, flexible schema for config
