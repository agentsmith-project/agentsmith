# 前端技术栈与国际化（i18n）策略 v1（定稿）

日期：2026-01-31  
适用：Web 前端（管理台 + Chat + AI Studio）  

---

## 1) 技术栈（你已确认）

- 框架：Next.js（React）+ TypeScript
- UI：TailwindCSS + shadcn/ui
- 图标：Lucide（SVG）

约束：
- UI 必须数据密集（表格/筛选/批量操作/详情抽屉优先），避免大面积装饰性留白
- 默认提供 Light/Dark（至少保证可扩展；v1 可先交付 Light，但组件与 tokens 不要阻塞 Dark）

---

## 2) 国际化范围（v1 必须：中英双语）

### 2.1 支持的语言
- `zh-CN`
- `en-US`

### 2.2 切换与记忆
- 顶部用户菜单提供语言切换（Language）
- 语言偏好保存优先级：
  1) 用户 Profile（若后端提供）
  2) LocalStorage
  3) 浏览器 `Accept-Language`

### 2.3 文案与格式化
- 所有可见文本必须来自 i18n 字典（禁止硬编码散落在组件里）
- 数字/时间/相对时间必须本地化：
  - en-US：`Jan 31, 2026`, `1,234`
  - zh-CN：`2026-01-31`, `1,234`（或按产品偏好）
- 错误文案：
  - UI 展示 “可读 message” + “error_code（可复制）” + “request_id（可复制）”
  - error_code 永远不翻译（用于工单与排障）

---

## 3) i18n Key 规范（建议）

建议 key 空间按模块分层，避免失控：
- `nav.*`
- `common.*`（按钮/通用状态）
- `auth.*`
- `project.*`
- `agents.*`
- `endpoints.*`
- `studio.*`（AI Studio 的历史兼容 namespace）
- `chat.*`
- `audit.*`
- `usage.*`
- `errors.*`（仅用于 UI 友好提示，不覆盖 error_code）

例：
- `common.save`
- `studio.turn.status.queued`
- `errors.permission_denied.title`

对外文案约定：
- 导航与页面标题统一使用 **AI Studio**。
- `studio.*` 键仅作为兼容，不应在用户文案中显示 “studio”。

---

## 4) 组件层面的多语言要求（验收口径）

- 语言切换后：
  - 导航、按钮、表格列名、空态、对话引导文案即时切换
  - 不影响请求上下文（workspace/project 不变）
- UI 不允许出现混用语言（除 error_code、ID、key 前缀等固定不可翻译内容）
