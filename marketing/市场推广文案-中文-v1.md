# MBOS 智能体平台 - 市场推广文案（中文）

---

## 主标题

**MBOS：企业级智能体治理平台**

一站式管理、发布与使用 AI 智能体，安全可控，开箱即用。

---

## 核心价值主张

### 一句话

> 以 Project 为中心的智能体治理平台，让企业安全、高效地接入与管理 AI Agent。

### 三大支柱

1. **治理中心** — 资源、权限、配额、用量、审计统一收敛到 Project
2. **权限精细** — 平台层 + 资源层双层权限，支持 deny wins，最小授权
3. **资源可控** — 多维限流、配额覆盖、护栏策略，分级别覆盖

---

## 功能亮点

### 多租户与项目管理

- **Workspace = 租户**：天然支持 SaaS 隔离
- **Project = 治理单元**：资源、成员、策略、用量归属清晰
- **可见性控制**：Public / Private，加入审批流程

### 权限与成员管理

- **四类角色模板**：Owner / Admin / Developer / User

- **权限点全覆盖**：
  - 平台层：Workspace、Project、Membership、Policy、Sources、Recipes、Agent、AgentThread、UserData
  - 资源层：KB、Endpoint 细粒度 ACL

- **成员配额覆盖**：按用户定制配额，支持历史追溯

### 智能体管理

- **External Agent**：外网 WebSocket 接入，常驻服务
- **Internal Agent**：平台托管，按 Session 拉起 Pod
- **Agent Service Key**：归属 Agent 签发，明文仅返回一次

### 资源与代理

- **UserData 能力**：DocDB、VectorDB、Storage，按 end-user 强隔离
- **共享 Endpoints**：LLM/HTTP 出网代理，凭据隐藏
- **Sources（文件）**：上传、AIReady、分页管理

### 审计与用量

- **审计日志**：操作可追溯，合规必备
- **用量统计**：请求、Token、路径分布

### 配置与策略

- **治理规则**：配额、限流、护栏，JSON 配置
- **资源限制**：Project 级限制，动态可调

---

## 适用场景

- **企业 AI 应用**：内部智能体统一接入与治理
- **多团队协作**：多 Project 隔离，权限与配额清晰
- **合规与审计**：操作全记录，用量可结算
- **混合部署**：SaaS 与私有化部署同架构

---

## 技术优势

- **两层权限**：Edge 粗粒度拦截 + Backend 细粒度裁决
- **AgentThread 可信上下文**：end_user 由服务端推导，不可伪造
- **多维限流**：Workspace / Project / Actor 分层控制
- **PostgreSQL + MongoDB**：关键数据强一致，配置可演进
