# 前端 data-testid 规范（v2）

日期：2026-02-05（最后更新：2026-02-06）

## 目标
- 提供稳定、可维护的测试选择器
- 避免依赖文案/样式导致的脆弱定位

## 命名规则
- 格式：`scope__element__state`
- 分隔符：双下划线 `__`
- 示例：
  - `login__submit`
  - `projects__create-btn`
  - `agents__table`
  - `page-state__error`
  - `studio__recipe-header`

## 适用范围
- 所有关键交互按钮
- 表格行/列表项
- 主要面板/对话框
- 页面状态容器（loading/empty/error/success）

## 使用原则
- **必须稳定**：不随文案/样式变化
- **必须唯一**：同一页面同一 testid 不重复
- **必须覆盖关键路径**：登录、项目、AI Studio、治理入口

## Playwright 使用建议
- 首选 `getByTestId()`
- 仅在必要时配合 `getByRole()`
- 表格行使用 `getByTestId('{scope}__table__row')`，配合 `data-row-id` 定位特定行

## 例外
- 纯展示元素可不加 testid
- 列表行可使用 `data-testid` + `data-row-id`
