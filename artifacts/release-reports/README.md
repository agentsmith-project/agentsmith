# Release Reports Directory

This directory contains generated or historical release-report snapshots.

Current release authority must come from the campaign-scoped evidence root:

- `artifacts/release-runs/<campaign-run-id>/summary.md`
- `artifacts/release-runs/<campaign-run-id>/summary.json`
- `artifacts/release-runs/latest.json`

Older checked-in files in this directory may preserve the Node/npm versions, paths, hostnames, and command outputs from the environment where they were generated. Treat those values as historical evidence metadata, not current setup guidance.
